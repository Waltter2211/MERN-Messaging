# 💬 MERN Messaging App

**A real-time messaging platform built with the MERN stack and Socket.io.**  
Add contacts, chat instantly, and explore a modern, responsive messaging UI.

![Node.js](https://img.shields.io/badge/Node.js-v20.14.0-green)
![Express](https://img.shields.io/badge/Express-v4.19.2-orange)
![React](https://img.shields.io/badge/React-v18.2.0-blue)

---

## ✨ Features

- 🧑‍🤝‍🧑 Add and manage contacts  
- 💬 Send and receive messages in real-time  
- 🧠 Built with Socket.io for seamless communication  
- 🎨 Responsive and modern UI  

---

## 🧪 Tech Stack

| Frontend | Backend  | Database | Communication |
|----------|----------|----------|---------------|
| React    | Express  | MongoDB  | Socket.io     |

> Written entirely in **TypeScript**

---

## ⚙️ Requirements

- Bash-compatible terminal  
- Local MongoDB instance

## 🚀 Run Locally

```bash
# 1. Download & extract the project
# 2. Navigate to the root directory
cd MERN-Messaging

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev

# 5. Open your browser
http://localhost:8000
```
